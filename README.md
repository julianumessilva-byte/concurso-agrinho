# Agro Forte, Futuro Sustentável: Equilíbrio entre Produção e Meio Ambiente

## 🌾 Sobre o Projeto
Este portal web foi desenvolvido especialmente para o **Concurso Agrinho 2026**, inserido na **Subcategoria 3 (Programação Front-End)**. O objetivo central da aplicação é conscientizar sobre as práticas agrícolas modernas que aliam a produtividade de culturas de milho e soja com a preservação ambiental no estado do Paraná.

## 🚀 Funcionalidades Principais
*   **Artigos e Novidades:** Textos informativos mapeando o ecossistema agrícola sustentável no Paraná.
*   **Dashboard Interativo de Mapas:** Gráficos estatísticos de barras estruturados puramente com HTML/CSS que carregam dados e crescem de forma animada via JavaScript conforme a região selecionada.
*   **Jogo Colheita Sustentável Avançada (Alta Complexidade):** Minijogo dinâmico com escolha de dificuldades (Fácil, Médio, Difícil), sistema progressivo de fases, cronômetro regressivo e grãos com pragas/estragados (❌) que geram penalidades na pontuação.
*   **Modo Escuro (Acessibilidade):** Alternância completa de cores visuais via CSS para conforto do usuário.
*   **Design Totalmente Responsivo:** Layout adaptável para smartphones, tablets e computadores por meio de CSS Media Queries que reorganizam o Grid de dados de forma fluida.

## 🛠️ Tecnologias Utilizadas
Para cumprir rigorosamente o item 8.3 do regulamento, o projeto foi feito com tecnologias puras e **sem o uso de nenhuma biblioteca ou framework**:
*   **HTML5:** Estruturação semântica de conteúdo.
*   **CSS3:** Layouts em Grid e Flexbox, animações de transição (`transition`) e variáveis nativas para controle de temas.
*   **JavaScript (ES6+):** Lógica assíncrona baseada em loops de tempo (`setInterval`), mapeamento de objetos estruturados e manipulação avançada de elementos dinâmicos do DOM.

## 📂 Organização do Repositório
O repositório mantém um ecossistema limpo e profissional, contendo apenas os arquivos funcionais necessários:
```text
├── index.html        # Estruturação e marcação semântica do portal
├── style.css         # Folha de estilo responsiva, animações e definições de cores
├── script.js         # Lógica de interatividade, gráficos dinâmicos e o jogo
└── README.md         # Documentação completa e guia técnico do projeto
```

## 🎮 Como Executar e Usar
1. Abra o arquivo `index.html` em qualquer navegador ou acesse o link de publicação do projeto via GitHub Pages / Vercel.
2. Digite seu nome na área de boas-vindas para testar a manipulação de dados por texto.
3. No painel de mapas, clique nos botões das regiões do Paraná e assista às barras de indicadores ecológicos se moverem e atualizarem em tempo real.
4. No painel de jogos, selecione a dificuldade desejada e clique em **"Iniciar Colheita"** para coletar grãos e marcar pontos.
5. Mude para o modo claro ou escuro a qualquer instante clicando em **"Alternar Modo"**.
