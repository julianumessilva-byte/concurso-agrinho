# Agro Forte, Futuro Sustentável: Equilíbrio entre Produção e Meio Ambiente

## 🌾 Sobre o Projeto
Este portal web foi desenvolvido especialmente para o **Concurso Agrinho 2026**, inserido na **Subcategoria 3 (Programação Front-End)**. O objetivo central da aplicação é conscientizar os cidadãos e estudantes paranaenses sobre a importância das práticas agrícolas modernas que aliam alta produtividade de culturas como milho e soja com a preservação ambiental e a sustentabilidade no estado do Paraná.

## 🚀 Funcionalidades Principais
*   **Artigos e Novidades:** Textos informativos sobre o ecossistema agrícola sustentável no Paraná.
*   **Mapas de Produção:** Painel interativo que demonstra dados ecológicos e econômicos regionais conforme o clique do usuário.
*   **Jogo Interativo (Colheita Sustentável):** Um minijogo dinâmico onde o usuário simula a colheita ágil de grãos de milho (🌽) e soja (🫘), evitando o desperdício técnico e acumulando pontuação.
*   **Modo Escuro (Acessibilidade):** Interface adaptável com um clique para alternância entre temas claros e escuros, garantindo conforto visual.
*   **Design Totalmente Responsivo:** Layout adaptável para dispositivos móveis, tablets e desktops através de CSS Media Queries estruturadas.

## 🛠️ Tecnologias Utilizadas
Para cumprir rigorosamente as diretrizes e restrições do regulamento (Artigo 8.3), o projeto foi desenvolvido utilizando apenas tecnologias Web puras/nativas, sendo **completamente vedado o uso de bibliotecas, frameworks ou merges externos**:

*   **HTML5:** Estruturação semântica do conteúdo (tags como `main`, `section`, `nav`, `article`).
*   **CSS3:** Estilização visual, layouts em Flexbox, variáveis nativas para controle de temas e Media Queries para responsividade.
*   **JavaScript (ES6+):** Lógica de programação pura, eventos de escuta (listeners), estruturas condicionais, manipulação nativa do DOM e geração dinâmica de elementos na tela.

## 🎮 Como Executar e Usar
1.  **Acesso ao Portal:** Abra o site publicado no ambiente de produção (**GitHub Pages** ou **Vercel**).
2.  **Identificação:** Insira seu nome na seção de identificação para receber uma saudação personalizada processada em tempo real por variáveis de memória do navegador.
3.  **Explorar Regiões:** Na seção de mapas, utilize os botões para ler informações ecológicas específicas das regiões Norte, Oeste e Sul do Paraná.
4.  **Jogar:** Vá até a seção do minijogo, clique em **"Iniciar Colheita"** e clique sobre os emojis de grãos antes que sumam da tela. Ao finalizar, clique em **"Parar Colheita"** para computar o seu desempenho ecológico.
5.  **Acessibilidade:** Utilize o botão **"Alternar Modo"** localizado no canto superior direito para alternar a interface entre modo claro e escuro a qualquer momento.
